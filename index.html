HML

Hybrid Markup Language

一门为图形与教学设计的轻量语言

下载 HML 查看语法

为什么是 HML

不追求全能，只追求刚好够用。

单文件实现

整个语言运行时，只有一个 .c 文件。没有依赖地狱，没有复杂构建。

图形优先

内置 SDL2 图形后端。画圆、画线、开窗口，一行搞定。

语法简洁

声明式模式头 + 清晰语句。画一个圆，只要 7 行。

可扩展

内置函数表清晰，想加功能，直接加一个 builtin 就行。

SDL2 运行时

Windows 下运行图形模式，需要 SDL2 动态库。

官方地址： github.com/libsdl-org/SDL/releases

下载后，把 SDL2.dll 放到 hml.exe 同一个目录即可。

使用方法

三步跑起来。

1. 准备文件

hml.exe
SDL2.dll
test-gfx.hml

2. 写一个 test-gfx.hml

@gfx 400 300 "SDL2 Test"

gclear(0x101820)
gcircle(200, 150, 80, 0xFFCC33)
gpresent()
gsleep(2000)

3. 运行

./hml.exe test-gfx.hml

出现黑底黄圆窗口，即表示 SDL2 配置成功。

从源码编译

需要 MinGW-w64 + SDL2 开发库。

命令行模式（无图形）：

gcc hml.c -o hml.exe -DNO_GRAPHICS -O2

图形模式（需要 SDL2）：

gcc hml.c -o hml.exe -lmingw32 -lSDL2main -lSDL2 -lm -O2

如果你用的是 MSYS2 / UCRT64，也可以直接： 

pacman -S mingw-w64-ucrt-x86_64-SDL2

常见问题

这几个坑，基本人人都会踩。

1. 提示找不到 SDL2.dll
把 SDL2.dll 放到 hml.exe 同一个目录。 不是系统目录，不是桌面，是 exe 旁边。
2. 提示 undefined reference to `WinMain'
编译时缺少 SDL2 的入口库。加上 -lmingw32 -lSDL2main 即可。
3. 窗口一闪而过
gsleep 时间太短，或者没写。 至少写 gsleep(2000) 让它停 2 秒。
4. 提示“图形未启用”
编译时没加 SDL2 参数。去掉 -DNO_GRAPHICS， 改用 -lmingw32 -lSDL2main -lSDL2 重新编译。
